# RETRO TETRIS // 1990

A small, dependency-free browser Tetris game with a deliberately nostalgic 1990s arcade / CRT aesthetic.

## Play

Open `index.html` in a browser, or deploy the repository with GitHub Pages / Vercel.

### Controls

- `←` / `→` — move
- `↑` — rotate clockwise
- `Z` — rotate counter-clockwise
- `↓` — soft drop
- `Space` — hard drop
- `Enter` — start / restart after game over

## Features

- Classic 10×20 falling-block board
- Seven tetrominoes
- Rotation and collision detection
- Line clearing
- Level progression
- Score and local high-score table
- Next-piece preview
- CRT scanline aesthetic
- Tiny square-wave sound effects
- Responsive layout
- No framework and no build step
